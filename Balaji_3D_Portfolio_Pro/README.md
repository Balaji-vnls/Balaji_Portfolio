# Balaji V N — 3D Portfolio Pro

A premium dark portfolio built with React, Vite, Three.js, React Three Fiber, Drei, Framer Motion, and Lucide icons.

## Run in VS Code
1. Extract the ZIP and open the `Balaji_3D_Portfolio_Pro` folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run:
   ```powershell
   npm.cmd install
   npm.cmd run dev
   ```
4. Open the local URL printed by Vite, usually `http://localhost:5173`.

If PowerShell blocks `npm`, use `npm.cmd` as shown above.

## Verify production build
```powershell
npm.cmd run build
npm.cmd run preview
```

## Personalize
- Edit the profile and projects in `src/main.jsx`.
- Change visuals and responsive styles in `src/styles.css`.
- Review the email, LinkedIn, GitHub, LeetCode, project links, and project descriptions before publishing.
- 3D scenes use WebGL and need a compatible browser. Google Fonts are loaded remotely.

## Included sections
- Animated 3D hero with a floating distorted icosahedron, orbital rings, stars, and sparkles
- About and stats
- KodNest internship
- Six project cards
- Skills and education
- Certifications and contact links
